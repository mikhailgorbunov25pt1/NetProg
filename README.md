# NetProg

Практическое задание 3 «Технологии сетевого взаимодействия в программах».

| Каталог    | Программа                         | Протокол | Порт |
|------------|-----------------------------------|----------|------|
| `daytime/` | клиент службы daytime (RFC 867)   | UDP      | 13   |
| `echo/`    | клиент службы echo (RFC 862)      | TCP      | 7    |

Сборка: `make` в каталоге программы (цели `all`, `debug`, `release`, `clean`).

Запуск:

```
./daytime <ip> [port]
./echo <ip> [port]
```

`echo` отправляет серверу каждую строку из stdin и печатает ответ, выход — Ctrl+D.
